# marywhite.github.io
Week 3 assessment

## Instructions

This project includes a simple vowel counting functionality. Follow the steps below to use it:

1. Open the `index.html` file in your browser.
2. Click the "Count Vowels" button.
3. Enter a string in the prompt that appears.
4. Open the browser console to see the result.

## Description

The `countVowel.js` file contains a function called `countVowel` that counts the number of vowels (a, e, i, o, u) in a given string. The function is triggered by a button click in the `index.html` file, which prompts the user to enter a string and then displays the number of vowels in the console.

## Example

To run the code in the browser, follow these steps:

1. Open the `index.html` file in your browser.
2. Click the "Count Vowels" button.
3. Enter a string in the prompt that appears.
4. Open the browser console to see the result.

Example output:
```
Your entry contained 3 vowels.
```
